This is version 1.0 (December 1994) of the model that the UC Berkeley Walkthrough Group
built and that Michael Kofler later exported to VRML. It is in the same coordinate frame
as the VRML files (inches, Z up). Each file begins with the authors' permission notice,
which must stay attached to any copy: use, copying, and modification are allowed;
redistribution for payment and commercial exploitation are not. Please cite it as the
"U.C. Berkeley Soda Hall WALKTHRU Model".
