Welcome to the SodaHall VRML JumpThru!

This is a VRML database of SodaHall, the computer science building of UC Berkeley.

This VRML model of Soda Hall was generated according to this report: vrmljumpthru report (in postscript)

If you want to see what the rooms in SodaHall look like, these are your options:

  • Standard version: gzip-compressed VRML files of (nearly) each individual room of SodaHall.

  • Inline version: use this version, if your browser / VRML plugin does not support gzip-decompression. Again you will find VRML files for each individual room. To save disk space, furniture is stored in seperate files. Unfortunately, downloading is pretty slow.

You can also access entire floors instead of individual rooms. This makes only sense if you have a lot of memory and hardware accelerated graphics.
  • Floors: VRML models of entire floors (without furniture).

Whatever version you choose, you need a VRML 1 browser or plugin. If you don't have one, you will probably find one for free at the VRML Repository.
If you want more information about SodaHall, have a look at the Soda Hall Home Page.
